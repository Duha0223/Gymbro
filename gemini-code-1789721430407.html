📖 Site User Manual & Guide

1. Workout Tracking & Granular Set Navigation

  • Restart Exercise: Click ↺ Restart Ex to restart the active exercise from its very first set.
  • Set Stepping: Use ⏮ Prev Set or ⏭ Next Set to jump seamlessly backward or forward across sets and movements.
  • Master Pause All: Instantly pauses the routine timer, YouTube video, and all playing ambient sound tracks together.

2. Multi-Track Ambient Sound Mixer

  • Layered playback: Play multiple nature and ambient sounds concurrently without cutting each other off.
  • Independent volume: Adjust sliders for rain, fire, forest, or stream independently.
  • Master controls: Click ▶ Start All or ⏸ Pause All directly inside the mixer.

3. YouTube Integration & Routine Management

  • Video Directory: Save exercise tutorials by custom folders, queue them, and save them as reusable workout playlists.
  • Routine Customizer: Reorder, configure reps/durations, and toggle movements at any time.
